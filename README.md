# HpM | Hecho pr Mujeres

HpM ha sido concebida como un modelo instrumental que busca disminuir el impacto negativo de los sesgos androcéntricos en la construcción de la historia de las disciplinas en Chile mediante la visibilización del aporte de sus pioneras. 

HpM es también una guía práctica que incorpora la perspectiva de género en el propio proceso investigativo desafiando los cánones modernos y objetivistas para la construcción de una historia de las pioneras, avanzando en la generación de un conocimiento transformador para ellas y sus contextos, así como también, contribuyendo a la generación de conocimiento transformador para la disciplina y la profesión.

Los componentes clave y las características de esta guía práctica hacen de HpM un modelo que permite que otros investigadores y otras investigadoras puedan replicar y escalar la acción epistemológica para construir la historia de las disciplinas a partir del aporte visibilizado de sus pioneras.

En este repsitorio de comparten datos sobre pioneras en Trabajo Social, que pueden servir de base a investigaciones que visibilicen a pioneras como María Olga del Solar.
